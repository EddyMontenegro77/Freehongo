Trends compare your recent practice with the period right before it, so you can see whether you are improving.

Period
The time window shown in the numbers and charts.
Skill
Shows all skills together or only one of them (reading, meaning or writing).
Numbers and changes
Each number summarizes the selected period. The chip next to it shows the change against the previous period of the same length: green means it went up and red means it went down.
Accuracy and activity
How correct your answers were and how much you practiced, day by day.
Accuracy by skill
One line per skill, to compare them. It only appears when all skills are selected.

You need to practice on a few different days before the charts show up.
