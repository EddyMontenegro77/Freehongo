# FreeHonGo frontend

This directory contains the Angular frontend for FreeHonGo.

For project-wide setup, architecture, environment variables and deployment instructions, see the [root README](../README.md).

## Commands

```bash
npm install
npm start
npm run build
npm test
npx tsc --noEmit -p tsconfig.app.json
```

The build script generates the ignored Angular environment files from environment variables before compiling.
