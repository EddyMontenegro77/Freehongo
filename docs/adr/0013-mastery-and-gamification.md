# ADR-0013 — Mastery and progress feedback

- Status: Accepted
- Date: 2026-11-24
- Decision type: Confirmed

## Context

Learning thousands of characters can feel directionless. Users need feedback based on characters they have actually attempted, not only on the size of the Japanese corpus.

## Decision

Show mastery based on attempted-character performance and reinforce progress with streaks, progress bars and dashboard summaries.

## Consequences

- The user receives meaningful short-term progress feedback.
- Gamification must remain grounded in real attempts and accuracy.
- Statistics and mastery definitions need to stay understandable and consistent.
