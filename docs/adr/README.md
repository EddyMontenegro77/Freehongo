# Architecture Decision Records

ADRs capture decisions that affect the structure or long-term behavior of FreeHonGo.

The initial records were reconstructed from the code and then confirmed by the project author. Keep future records focused on one durable decision rather than one implementation detail.

## How to add an ADR

1. Copy [`template.md`](template.md).
2. Use the next number and a short kebab-case title.
3. Describe context, decision, alternatives and consequences.
4. Mark the status as `Proposed`, `Accepted`, `Superseded` or `Rejected`.
5. If reconstructed, cite the code or schema evidence.
